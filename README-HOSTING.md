# YCC PCC Legal Site — free hosting setup

This folder is ready for a simple static host such as GitHub Pages.

## GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `ycc-pcc-legal`.
2. Upload **the contents of this folder** to the repository root:
   - `index.html`
   - `privacy/`
   - `terms/`
   - `assets/`
   - `.nojekyll`
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then Save.
6. After GitHub publishes it, the site will normally be:

   `https://YOUR-GITHUB-USERNAME.github.io/ycc-pcc-legal/`

7. Use these in TikTok:

   **Terms of Service URL**
   `https://YOUR-GITHUB-USERNAME.github.io/ycc-pcc-legal/terms/`

   **Privacy Policy URL**
   `https://YOUR-GITHUB-USERNAME.github.io/ycc-pcc-legal/privacy/`

## Important before production use

These pages accurately describe the current private/local-first PCC TikTok integration at a high level. If PCC becomes a public/commercial product, onboards other people, expands TikTok permissions, starts publishing content, or materially changes how TikTok data is processed, update the pages and obtain appropriate legal review for the jurisdictions in which the product is offered.
